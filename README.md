# LinkGallery

Android-приложение для просмотра галереи изображений по списку ссылок из внешнего текстового файла.

## Функциональные возможности

*   **Два экрана**:
    *   **Сетка (Grid)**: Адаптивный список превью изображений. Количество столбцов меняется в зависимости от ширины экрана (размер ячейки 100-120 dp). Поддерживает поворот экрана.
    *   **Полноэкранный режим**: Отображение оригинала изображения при нажатии на превью.
*   **Интерактивный Onboarding**: Система "Coach Marks" (полупрозрачные подсказки) при первом запуске, которые анимированно указывают на ключевые элементы интерфейса (переключатель темы, ячейки галереи).
*   **Загрузка и синхронизация данных**: 
    *   Автоматическое скачивание файла `images.txt` с сервера при запуске.
    *   Кэширование списка в локальной базе данных (Room).
    *   **Auto-retry**: Если файл или изображения не загрузились из-за отсутствия сети, приложение автоматически повторит попытку при восстановлении соединения.
    *   **Фоновое обновление**: Использование **WorkManager** для периодической синхронизации данных (раз в 24 часа) в фоновом режиме, что гарантирует актуальность контента даже при редком открытии приложения.
*   **Кэширование**:
    *   Превью (уменьшенные копии) и оригиналы сохраняются на диск в приватный каталог приложения.
    *   При повторном запуске данные загружаются из локального кэша.
*   **Заглушки (Placeholders)**:
    *   Специальные индикаторы для ссылок, не являющихся изображениями.
    *   Индикаторы ошибок, если валидное изображение не удалось загрузить, с возможностью ручного перезапуска.
*   **Темы**: Полная поддержка светлой и ночной темы.
*   **Pinch-to-zoom**: Приближение и удаление изображения жестами пальцев.
*   **Пагинация**: Возможность перелистывания изображений (свайпы влево/вправо) в полноэкранном режиме.
*   **Immersive Mode**: Переключение в полноэкранный режим и обратно по тапу на экран (скрытие/показ TopBar, системной панели уведомлений и навигации).
*   **Интеграция**: Возможность поделиться URL изображения или открыть прямую ссылку в браузере.

## Технологический стек
*   **Язык**: Kotlin
*   **UI**: Jetpack Compose (Material 3)
*   **Архитектура**: Clean Architecture + MVI (Reducer pattern)
*   **DI**: Hilt
*   **Сеть**: Retrofit, OkHttp
*   **База данных**: Room
*   **Фоновые задачи**: WorkManager
*   **Загрузка изображений**: Coil
*   **Тестирование**: MockK, Coroutines Test (Unit-тесты для ViewModel и Repository)

## Поддерживаемые версии Android
*   **Minimum SDK**: 24 (Android 7.0)
*   **Target SDK**: 37 (Android 15)

## Установка
1. Клонируйте репозиторий.
2. Откройте проект в Android Studio Ladybug (или новее).
3. Соберите и запустите приложение на эмуляторе или реальном устройстве.
